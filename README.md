# Flame

A paper-trading terminal for [flame.trading](https://flame.trading). Real markets, play money.

This repository is at its baseline: the app shell, the design system and a full specification. Start with [`CLAUDE.md`](CLAUDE.md), then the documents in [`docs/`](docs).

```bash
npm install
npm run dev
```

Paper trading only. Nothing here places real orders or handles real money, and nothing in it is financial advice.
